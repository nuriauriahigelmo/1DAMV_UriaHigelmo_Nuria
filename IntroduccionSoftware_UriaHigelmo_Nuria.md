# Introducción al Software

## ¿Qué es un programa informático?

Un programa informático es un conjunto de instrucciones que le indican a un ordenador qué tiene que hacer. Estas instrucciones se crean utilizando un lenguaje de programación y permiten realizar diferentes tareas, como hacer cálculos, mostrar información o utilizar una aplicación.

## Diferencia entre código fuente, código objeto y código ejecutable

**Código fuente:** 

Es el código que escribe el programador utilizando un lenguaje de programación. Está pensado para que las personas puedan leerlo, entenderlo y modificarlo.

**Código objeto:** 

Es el resultado de traducir el código fuente a un lenguaje más cercano al que entiende el ordenador. Se genera durante el proceso de compilación y todavía no es necesariamente el programa final que podemos ejecutar.

**Código ejecutable:** 

Es el archivo final que el ordenador puede ejecutar para poner en funcionamiento el programa. Por ejemplo, en Windows muchos programas ejecutables tienen la extensión `.exe`.

## Etapas del desarrollo del software

El desarrollo de un programa pasa por varias etapas desde que surge la idea hasta que el programa está terminado y se sigue utilizando.

1. **Análisis:** Se estudia qué problema queremos resolver y qué necesita hacer el programa.

2. **Diseño:** Se decide cómo se va a organizar y cómo va a funcionar el programa antes de empezar a programarlo.

3. **Programación:** Se escribe el código utilizando el lenguaje de programación elegido.

4. **Pruebas:** Se comprueba que el programa funciona correctamente y se buscan posibles errores.

5. **Implementación:** El programa se pone en funcionamiento para que pueda ser utilizado.

6. **Mantenimiento:** Una vez que el programa está funcionando, se corrigen errores y se pueden añadir mejoras o nuevas funciones.
